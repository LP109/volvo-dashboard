Home Dashboard - Terms and Privacy

Home Dashboard is a private, non-commercial application. It shows the status of the owner's own Volvo on a self-hosted dashboard inside the owner's home network. It is not offered to the public.

What data is used

After you sign in with your Volvo ID and give consent, the application reads vehicle data through the Volvo Cars APIs: battery level, electric range, charging state, fuel level, odometer, door, window and lock status, tyre and service warnings, and the vehicle location.

How the data is used

  • The data is only read. The application never sends commands to the vehicle.
  • The data is shown on a dashboard in the owner's home and is stored only on the owner's own server.
  • The data is never sold, shared with third parties or used for advertising.
  • Access tokens are stored only on the owner's own server and can be revoked at any time.

Revoking access

You can stop the application's access at any time by revoking its consent in your Volvo ID account, or by removing the stored tokens from the dashboard server.
